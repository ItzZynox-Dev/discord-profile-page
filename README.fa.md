# صفحه پروفایل دیسکورد

[English](README.md) | **فارسی**

یک صفحه پروفایل شخصی در قالب **یک فایل HTML** و بدون وابستگی، همراه با **وضعیت زنده دیسکورد**: آواتار، دکوراسیون آواتار، بج‌ها، وضعیت آنلاین/بیکار/مزاحم نشوید و بازی یا آهنگ اسپاتیفایی که در حال استفاده‌اید. تم تیره، ریسپانسیو و بدون نیاز به بیلد.

## امکانات

- نمایش زنده وضعیت، نام، آواتار، دکوراسیون آواتار و بج‌ها از طریق API سرویس [Lanyard](https://github.com/Phineas/lanyard) (هر ۲۰ ثانیه به‌روزرسانی می‌شود)
- کارت‌های شبکه‌های اجتماعی (تلگرام، یوتیوب، توییتر/X، اینستاگرام، تیک‌تاک، گیت‌هاب، توییچ، لینکدین، وب‌سایت)
- بخش مهارت‌ها و تکنولوژی‌ها با آیکون‌های SVG
- کاملاً ریسپانسیو، فقط یک فایل `index.html`، بدون فریم‌ورک

## شروع سریع

1. **وارد سرور Lanyard شوید** ← <https://discord.gg/lanyard>. این سرویس فقط کاربرانی را ردیابی می‌کند که عضو این سرور باشند؛ بدون این مرحله وضعیت لود نمی‌شود.
2. حالت توسعه‌دهنده را در دیسکورد فعال کنید (*Settings ← Advanced ← Developer Mode*)، روی نام خودتان راست‌کلیک کنید و **Copy User ID** را بزنید.
3. فایل `index.html` را باز کنید و بخش تنظیمات ابتدای تگ `<script>` را ویرایش کنید:

   ```js
   const DISCORD_ID = "YOUR_DISCORD_USER_ID";

   const PROFILE = {
     displayName: "Your Name",
     pageTitle:   "My Profile",
     about:       "یک معرفی کوتاه از خودتان بنویسید…",
   };
   ```

4. آرایه `socials` را ویرایش کنید: مقدار `value` (متن نمایشی) و `link` را بنویسید. برای مخفی کردن یک کارت، `link: ""` بگذارید.
5. آرایه `stack` را مطابق مهارت‌های خودتان تغییر دهید یا آیتم‌ها را حذف کنید.
6. فایل `index.html` را در مرورگر باز کنید تا پیش‌نمایش را ببینید.

## اختیاری: بج‌های اضافه

بج‌های Nitro، Server Booster و Quest/Orb از طریق API عمومی دیسکورد در دسترس نیستند. آن‌ها را به‌صورت دستی در `STATIC_BADGES` اضافه کنید (روش پیدا کردن هش هر بج در خود فایل توضیح داده شده است).

## انتشار رایگان با GitHub Pages

1. این مخزن را Fork کنید (یا نسخه خودتان را در یک مخزن جدید آپلود کنید).
2. به **Settings ← Pages** بروید.
3. در بخش *Build and deployment* گزینه **Deploy from a branch** را انتخاب کنید، شاخه `main` و مسیر `/ (root)` را بزنید و ذخیره کنید.
4. بعد از یکی دو دقیقه صفحه شما در آدرس `https://<username>.github.io/<repo>/` در دسترس خواهد بود.

## نکات

- صفحه فونت‌ها را از Google Fonts و داده‌ها را از `api.lanyard.rest` و `cdn.discordapp.com` می‌گیرد، پس به اینترنت نیاز دارد.
- اگر وضعیت خطا نشان داد، کنسول مرورگر (F12) را باز کنید. رایج‌ترین دلیل، عضو نشدن در سرور Lanyard است.
